# Hi there 👋 I'm Long

Embedded software engineer. Automotive, model-based design.

I studied electronics and telecommunications, and stayed in embedded because it's one
of the few places where the code has to survive contact with physical reality. A model
that looks right in simulation still has to hold up on a bus, in a vehicle, at temperature.
That gap is the interesting part.

Most of my day is Simulink, AUTOSAR and CAN. Most of what I publish here is the
tooling around that — the parts of the workflow that were still being done by hand
and probably shouldn't be.

Lately I've been spending my off-hours on AI. Partly curiosity, partly because the
boring half of embedded work — reading diffs, checking traceability, spotting the one
signal that changed — looks a lot like something a machine should be helping with.

I write things down more than I talk about them. If something here is useful to you,
or wrong, open an issue — both are welcome.
